# 다중 칸 건물의 전력망 연결 판정 개선

## 1. 개요
- **구분**: 기능 개선 (Feedback / Improvement)
- **상태**: 분석 완료 및 개선 대기 (Open)
- **관련 시스템**: `PowerGridSystem`, `ChunkMapSystem`, `BuildingFootprintUtility`

---

## 2. 현상 및 문제점
- 크기가 2×2 또는 3×3인 건물은 현재 footprint 내부의 `(1, 1)` 기준 칸이 전력망의 공급 범위 안에 들어왔을 때만 전력을 공급받습니다.
- 건물의 다른 점유 칸이 전력망 공급 범위에 포함되어 있어도 기준 좌표가 범위 밖이라면 건물이 전력망에 연결되지 않습니다.
- 이로 인해 건물 외형과 전력 공급 범위가 실제로 맞닿아 있는데도 전력이 공급되지 않는 것처럼 보여 배치 결과를 직관적으로 예측하기 어렵습니다.

---

## 3. 원인 분석
- [`PowerGridSystem.Participants.cs`](../../Assets/Scripts/Systems/Power/PowerGridSystem.Participants.cs)의 `ReconnectPowerParticipants()`는 참가자의 `GridPosition.gridPosition` 한 칸만 가져와 전력망 연결을 판정합니다.
- 해당 좌표만 `TryResolvePowerGrid()`와 `TryGetNearestPowerPole()`에 전달하므로, 다중 칸 건물의 전체 footprint는 판정 대상에 포함되지 않습니다.

---

## 4. 요구사항 (피드백 내용)
- 2×2, 3×3 등 여러 칸을 점유하는 건물은 기준 좌표 하나가 아니라 건물의 전체 footprint를 기준으로 전력망 연결 여부를 판정합니다.
- 건물이 점유한 칸 중 **하나라도 전력망의 공급 범위에 포함된다면 해당 건물에 전력이 공급**되어야 합니다.
- 건물의 크기와 회전 방향이 달라져도 실제 점유 칸을 기준으로 동일한 규칙을 적용해야 합니다.

---

## 5. 완료 조건
1. 1×1 건물의 기존 전력망 연결 동작이 유지됩니다.
2. 2×2 및 3×3 건물은 점유 칸 중 하나 이상이 전력 공급 범위에 포함되면 전력망에 연결됩니다.
3. 건물의 기준 좌표가 공급 범위 밖이어도 다른 점유 칸이 범위 안이라면 전력이 공급됩니다.
4. 건물의 모든 점유 칸이 공급 범위 밖이라면 전력망에 연결되지 않습니다.
5. 회전된 비정방형 다중 칸 건물도 회전 후 실제 footprint를 기준으로 올바르게 판정됩니다.
