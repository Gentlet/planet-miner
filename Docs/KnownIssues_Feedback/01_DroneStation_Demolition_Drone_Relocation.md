# 드론 스테이션 철거 시 보관 드론 처리 개선

## 1. 개요

- **구분**: 기능 개선 (Feedback / Improvement)
- **상태**: 구현 완료 (Resolved)
- **관련 시스템**: `DroneIdentityConversionSystem`, `BuildingDestroySystem`, `DroneStationStorageSystem`

---

## 2. 현상 및 문제점

- 드론 스테이션 철거 시 보관 중인 드론이 `ItemTypeEnum.Drone` 월드 아이템으로 변환되어 바닥에 드롭되었습니다.
- 철거 직후 주변 공간을 차지하고, 별도의 회수 작업으로 다시 수거해야 했습니다.

---

## 3. 요구사항

- 보관 드론을 월드 아이템으로 떨어뜨리지 않습니다.
- 수용 가능한 다른 드론 스테이션 또는 메인 스테이션으로 이동 및 재배치합니다.
- 여러 드론을 옮길 때 모든 목적지의 실제 수용 가능 용량을 반영합니다.
- 안전하게 재배치할 수 없다면 드론 identity를 유지하고 철거를 보류합니다.

---

## 4. 구현 결과

- 철거 대상 정거장의 모든 보관 드론을 변경 전에 검증하고 목적지를 선계산합니다.
- 같은 드론 네트워크의 가까운 정거장을 우선하고, 공간이 없으면 다른 네트워크의 정거장까지 탐색합니다.
- 목적지가 정해진 드론은 active identity를 유지한 채 `Returning` 상태로 전환되어 해당 정거장으로 비행합니다.
- 드론 월드 아이템 및 자동 회수 작업은 생성하지 않습니다.
- 모든 드론을 수용할 공간이 없으면 일부만 이동시키지 않고 철거 요청을 보류합니다.

---

- [x] 대체 정거장이 없을 때 기존 보관 상태를 유지하며 철거를 보류합니다.
