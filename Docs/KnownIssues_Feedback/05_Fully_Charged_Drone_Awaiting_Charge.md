# 완전 충전된 드론의 충전 대기 상태 지속

## 1. 개요
- **구분**: 버그 / 알려진 문제 (Bug / Known Issue)
- **상태**: 확인 및 수정 대기 (Open)

---

## 2. 현상 및 문제점
- 드론의 배터리가 모두 충전되었음에도 `충전 대기 중` 상태가 계속 유지됩니다.
- 충전이 완료된 드론이 보관 상태로 전환되지 않아 화면상에 지속적으로 표시됩니다.
- 실제 충전 필요 여부와 표시되는 상태 및 드론의 시각적 노출이 일치하지 않습니다.

---

## 3. 요구사항 (피드백 내용)
- 배터리가 모두 충전된 드론은 더 이상 `충전 대기 중` 상태에 머물지 않아야 합니다.
- 완전 충전된 드론은 정상적인 보관 상태로 전환되어야 합니다.
- 보관 상태로 전환된 드론은 기존 보관 드론 표시 규칙에 따라 화면에서 숨겨져야 합니다.

---

## 4. 완료 조건
1. 드론의 배터리가 최대치에 도달하면 `충전 대기 중` 상태가 종료됩니다.
2. 완전 충전된 드론이 정상적인 보관 상태로 전환됩니다.
3. 보관 상태의 완전 충전 드론이 화면에 지속적으로 표시되지 않습니다.
4. 충전이 완료되지 않은 드론은 필요한 동안 기존 충전 또는 충전 대기 흐름을 유지합니다.
