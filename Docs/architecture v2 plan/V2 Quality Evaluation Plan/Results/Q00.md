`git status --porcelain=v1 --untracked-files=all`, HEAD, 브랜치, staged/unstaged diff 통계를 확인했다. 최초 Git 조회는 실행 계정과 저장소 소유자 차이로 거부되어 이후 `git -c safe.directory='C:/Projects/unity/PlanetMiner/planet miner' ...`로 조회했다. 전역 Git 설정은 변경하지 않았다. ignored 파일·Unity 캐시의 동일성은 이 Git 기준선의 보장 범위가 아니다.

기존 삭제를 복구하거나 새 문서를 stage/commit하지 않았다. 이번 변경 대상은 이미 미추적 상태였던 이 평가 문서뿐이다. 수정 전 문서 SHA-256은 `BF3B5121D5051D254F9BEF361F13B09F2F98A9925AB127CF1D9206C72678122C`이다.

갱신 후 HEAD·전체 미추적 파일을 포함한 Git 상태·staged/unstaged 변경 목록을 재조회하여 시작 상태와 같음을 확인했다. 아래 버전 파일 3개의 SHA-256도 그대로이며, 후속 33개 단계는 모두 미착수다. 미추적 문서의 내용 변경은 Git status 상태 문자에 따로 드러나지 않으므로, 동일 상태가 문서 무변경을 뜻하지는 않는다.

#### 8.5 제외 범위와 구현 경계

- 전력망, 드론 운송, 연구 진행, 주 시설 자동 부트스트랩, 게임 입력·카메라 제어·UI Toolkit 컨트롤러, 실제 바닥 Sprite 청크 렌더링은 현재 `Assets/Scripts/` 파일 목록과 시스템/MonoBehaviour 선언 확인 범위에서 구현 시스템을 찾지 못했다. 해당 기능의 완성도 평가는 제외한다. enum·설정·프리팹·패키지만으로 기능 존재를 인정하지 않는다.
- 공사 현장의 바닥 아이템 회수·대기 해제 구현은 확인하지 못했다. `AwaitingItemClearance` 검색에서는 선언, 배치 시 설정, 완료 Job의 보류 조건만 확인됐다. 회수 기능 자체의 완성도는 제외하되, 이미 구현된 배치·완료 경로가 이 상태에 의존하는 영향은 Q23/Q25에 포함한다.
- 미구현 기능도 현재 구현의 필수 의존성으로 발견되면 해당 연결부를 평가한다. 새 게임 규칙을 만들어 공백을 채우지 않는다.
- 실제 플레이·입력·화면·성능 측정·플랫폼별 빌드·WebGL·저장 지속성은 이번 기준선으로 보장하지 않는다. Q00에서는 실행 검증을 전부 제외했다.
- V1 전체와의 비교, 무관한 레거시 설계 문서, 전체 에셋·패키지 소스 감사, Library/Temp/Logs 내용, 의존성이 확인되지 않은 다른 기능은 제외했다.
